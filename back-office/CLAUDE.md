# CLAUDE.md（back-office/）

このディレクトリで作業するときに毎回自動で読み込まれるファイルです。使い方（画面操作）は
[README.md](README.md) を参照してください。ここに書くのは、セッションをまたいで覚えておくべき
業務ルールと、実データを見て分かった注意点です。新しいセッションでは、以前のように
HANDOFF.md を貼り付けなくても、この内容が自動的に文脈として渡されます。

## このプロジェクトの位置づけ

- 鳴鳳堂の社内用ツール。`back-office/`（資金繰り・債権債務管理）と `back-office/cashbook/`
  （資金表→現金出納帳）の2本。公開サイト（www.meihodo.com / GitHub Pages）には**含まれない**
  （`.vercelignore` と `deploy.yml` で除外済み）。公開サイト側のファイルには一切触れない。
- ビルド不要・通信なしの静的ページ。データは利用者のブラウザの localStorage にのみ保存され、
  Claude 側にも外部にも送信されない。
- ロジックは `core.js` / `cashbook/cashbook.js` に分離してあり、`npm run test:back-office` で
  テストする。消込・締日計算・資金繰りの判定を変更するときは、**先にテストへ期待値を書いてから**
  ロジックを直す（お金の計算のため目視確認だけでは済ませない）。

## 業務ルール（お客様に確認済み・変更不要）

- **色分けより通帳突合を優先する。通帳が正。** 資金表の文字色（青＝銀行振込／黒・赤＝現金）は
  一次判定の目安に過ぎない。青字でも通帳に同じ動きが無ければ確定させない。逆に色が黒・赤でも
  通帳に同じ動きがあれば銀行取引として扱う。
- **修正・再分類は「確認 → 確定」を経てから正式なものとして扱う。** 色だけで決まった判定は
  `confident:false` を返し、必ず人の確認に回す設計を維持すること。
- **本部・関連会社（米粉文化・遊学社）との内部勘定に特別な除外ルールは不要。** 仮受消費税・
  法人税引当金・貸付金・本部立替金などの高額科目も、最終的には実際に銀行口座を通って精算される。
  通常の銀行CSV突き合わせで自動確定する設計のままでよい（実データで検証済み）。
- **口座振替（自動引落）は資金表に記載があっても現金出納帳からは除外する。** 例：浄化槽点検の
  引落。現金の動きではないため、色分けが黒・赤であっても現金出納帳の対象にしない。
- **ATM引き出しは使途に応じて複数の取引に分割することがある。** 1件の引き出しの中に、現金として
  手元に残る分と、特定の支払先への現金返済に充てた分が混在する場合など。分割後の内訳合計は
  必ず元の金額と一致させる（`splitEntry` が一致しない分割を拒否する仕様を維持すること）。

## 実データで分かった資金表の癖（対応済み）

- 摘要（取引先・内容）列の見出しが空欄の資金表がある。列名で摘要列を特定できないときは、
  中身の文字量から推測するフォールバックがある（`inferDescriptionColumn`）。ユーザーが列対応を
  明示指定したときは上書きしない。
- 資金表の「会計処理」列（済み／未処理）は、済みの行を当月の作業対象から自動除外するのに使う
  （銀行分はAPI連携で自動記帳されるため、主に現金分の手入力完了を示す）。
- 実際の資金表・通帳CSVは、数式が壊れている／使用範囲が100万行超に膨れている、といった
  Excelの構造的な問題を抱えていることがある。お客様のExcelファイルを直接編集する依頼では、
  ツールのロジックとは別に、ファイル自体の健全性（数式・使用範囲）も確認すること。

## 過去の確定実績（5月分・判断の参考例）

- 検算式は「現金純増減 ＝ 資金表残高の増減 − 銀行通帳上の動き」。5月は目標値 +7,012円、
  月末残高 156,756円で確定。この数値は `cashbook/README.md` 記載の通り、テストの基準値にも
  組み込み済み。
- 色分け修正の実例：①外注労務費の再分類、②浄化槽点検→口座振替と判明し除外、③現金返済取引の
  再分類。④ATM引き出し1件を「現金として残る分」と「特定支払先への現金返済分」に分割。
  同種のケースが出たら、この前例に沿って判断してよい。

## セッション運用

- お客様はExcel・会計に詳しいが、Claude Codeやリポジトリの仕組みには不慣れ。専門用語を避け、
  操作は番号付き手順で、初心者向けに説明する。
- ファイルのやり取りは常に手動（チャットへの添付／ダウンロード）。お客様のローカルPCや
  Googleドライブ等の外部ストレージに自動でアクセスすることはできない。
- 資金繰り・現金出納帳ツール本体（Web版）はこのリポジトリの `back-office/` から
  Claude Artifact として公開されている。ツール本体（GitHub側）を修正したら、同じファイルパスで
  Artifact を再公開すればリンクは変わらず更新される。
